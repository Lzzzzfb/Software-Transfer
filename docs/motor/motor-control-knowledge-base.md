# LK-MD2202 电机控制知识库

本文描述当前活动方案。旧 STM32/TMC2209 工程仅作为可回退历史材料保存在
`firmware/TMC2209`，不得用于当前驱动板烧录或通信。

## 1. 系统边界

```text
ROCK 4B+ (PyQt6)
  └─ USB-RS485，9600 8N1
       └─ LK-MD2202，Modbus-RTU 地址 1
            ├─ M1 → X 轴，M1-K → X 零点开关
            └─ M2 → Y 轴，M2-K → Y 零点开关
```

LK-MD2202 直接完成脉冲产生、限位和回零。STM32、ST-LINK、PB3～PB6、Z 轴、
旧 ASCII 命令和 HEX 文件均不在活动链路中。激光器和旧“数据处理”功能不移植。

## 2. 接线与限位

- X 电机接 M1，Y 电机接 M2；
- X 零点开关接 M1-K 与 GND；
- Y 零点开关接 M2-K 与 GND；
- 开关为纯常开触点，到达零点时闭合接地；
- 驱动板两轴限位模式固定为“零点限位”；
- 每轴只有零点限位，正向终点依赖回零后的驱动板终点参数。

常开触点无法检测断线。首次通电应先手动压下开关，通过只读状态确认只改变对应
轴的限位位，再以可立即断电、机构安全且已经实测能平稳运行的速度验证短距离动作。
本机实测10000 pps运行平滑，而100/500 pps可能只有噪声不转，因此不能把“越低越安全”
当作通用结论。

## 3. 已确认机械换算

| 项目 | X/M1 | Y/M2 |
|---|---:|---:|
| 行程 | 15 mm | 15 mm |
| 终点位置 | 4800 pulse | 4800 pulse |
| 换算 | 320 pulse/mm | 320 pulse/mm |
| 最小软件步距 | 0.003125 mm | 0.003125 mm |

步距角、细分和终点脉冲是一组机械真值。当前版本固定为 1.8°、8 细分和
4800 pulse；若驱动板读回不一致，毫米运动和扫描会被拒绝，用户需在“电机设置”
中恢复建议默认值并完成回读校验。

## 4. 建议默认参数

| 参数 | X/M1 | Y/M2 |
|---|---:|---:|
| 步距角 | 1.8° | 1.8° |
| 细分 | 8 | 8 |
| 运行电流 | 50% | 50% |
| 限位模式 | 零点限位（锁定） | 零点限位（锁定） |
| 终点位置 | 4800 pulse（锁定） | 4800 pulse（锁定） |
| 停止电流 | 无锁定 | 无锁定 |
| 加速参数 | 10000 | 10000 |
| 减速参数 | 10000 | 10000 |
| 位置速度 | 10000 pps | 10000 pps |
| 上位机方向反转 | 关闭 | 关闭 |

“恢复建议默认值”只填充表单，不自动写设备。“应用”会显示差异、只写变化字段，
最后处理地址/波特率，并重新读取全部配置确认。

## 5. 通信原则

- 详细寄存器见 `lk-md2202-modbus-protocol.md`；
- 自动识别只发送功能码 `0x03` 的身份、配置和状态读取；
- USB VID/PID 只用于枚举信息，不作为驱动板身份；
- 自动发现排除 ROCK 4B+ 板载调试串口 `ttyFIQ*`，只自动探测USB串口候选；
- 读取可有限重试；运动、回零、停止和参数写入超时不得盲目重发；
- 32 位位移、速度和终点参数用一次 `0x10` 连续写入高低寄存器；
- CRC、异常码、地址、功能码和响应长度均严格校验；
- GUI 线程不阻塞等待串口，也不使用 `sleep` 实现步时。

可在 Windows 或 ROCK 4B+ 执行只读探针：

```text
python -m spectrometer.motor.probe --json
```

## 6. 坐标与异常恢复

LK-MD2202 报告驱动脉冲位置；上位机另维护本次运行内的软件零点偏移。

- 软件清零不运动，可使显示坐标出现负值；
- 软件回零依据当前会话的软件偏移返回 0；
- 机械回零只有在本次动作实际观察到限位“断开→闭合”，并最终确认停止、累计位置0和限位闭合时才建立已校准状态；
- 软件零点和校准状态不做掉电恢复；
- 未机械回零仍允许手动运动和扫描，但开始扫描前必须明确确认风险；
- 已校准时，设备目标脉冲严格限制在 0～4800；
- 卡滞、掉步、断电或联轴器打滑会使开环坐标与真实位置不一致，此时应停止，
  不能把驱动板累计脉冲当作真实位移证据。

每轴主界面提供“脱离卡死”：

1. 速度框允许正负数；“设速”把绝对值写为正常位置速度；
2. 单击“脱离卡死”时把带符号值写入驱动板速度控制寄存器；
3. 初始限位闭合时，检测到限位释放立即写速度0；
4. 初始限位断开时，如果限位变为闭合，视为方向风险并立即停止；
5. 限位无变化时，最多运行1秒，同时受4800 pulse理论时间上限限制；
6. 停止后保持未校准，由操作员确认实际位置并重新机械回零；
7. 机械回零开始时限位已经闭合会被拒绝，不能用“累计位置0+限位闭合”直接冒充有效回零；
8. 机械回零超时按位置速度计算并限制在2～5秒，防止限位失效时长期顶住机械端。

如果速度0、位置急停或运行状态回读失败，软件显示“停止状态未知”，禁止新的电机运动和扫描。此锁定不能用“清除故障”直接绕过；必须重新读取并确认X/Y均已停止。RS-485完全断开时软件不能保证驱动板停止，操作员必须切断驱动板电源。独立光谱仪采集不受该电机锁定影响。

方向反转只改变上位机运动方向映射，默认关闭。首次实机必须以安全、短距离分别
确认 X/Y 正方向和 LK-MD2202 内部回零方向。

## 7. 扫描与光谱联动

参数为 `x, y, n, m, X步数, Y步数, 步时`：

1. 每轮先启动一次光谱仪连续采集；
2. X 正向走 `x`，Y 正向走 `y`，然后 X 反向走 `x`，按蛇形交替；
3. Y 共执行 `n` 个行程，X 共执行 `n+1` 个行程；
4. 每个完整 X/Y 行程按相应步数分成整数脉冲子步，相邻动作间等待一次步时；
5. 最后一段 X 完成后停止采集并等待保存完成；
6. 电机在不采集状态下返回本轮起点，再开始下一轮；
7. 共执行 `m` 轮，每轮独立保存并写扫描清单。

默认 X/Y 步数均为 1，步时为 0。用户停止、限位异常、电机掉线、运动结果未知或
光谱仪失败都会停止当前轮；故障后不会盲目自动复位。

未校准仍不强制禁止扫描；软件在启动前显示风险确认，用户确认后可以继续。只有电机仍在运动、正在脱离卡死或停止状态未知时才禁止扫描。

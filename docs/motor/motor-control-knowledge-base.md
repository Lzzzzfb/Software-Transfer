# 电机控制知识库

## 1. 系统组成

本项目电机子系统由以下部分组成：

- STM32F103C8T6；
- 四颗 TMC2209：
  - X：地址 `0x00`；
  - Y1：地址 `0x01`；
  - Y2：地址 `0x02`；
  - Z：地址 `0x03`；
- 三个逻辑运动轴：
  - X 使用一台电机；
  - Y 使用两台同步电机和同一组 STEP/DIR；
  - Z 使用一台电机；
- STM32 USB CDC 与 ROCK 4B+ 通信；
- PA9 单向发送 TMC2209 UART 配置。

固件权威源位于：

```text
firmware/TMC2209
```

原始导入提交为 `d10340f`，导入时与
`D:\codex\Linux转移电机控制\SM2009 - 完整版\TMC2209`
逐文件 SHA-256 比较一致。

## 3. 脉冲换算

基本步数：

```text
360° / 18° = 20 full-step/rev
```

TMC2209 `CHOPCONF=0x140100C3` 中 MRES 对应16微步：

```text
20 × 16 = 320 pulse/rev
```

丝杆导程为0.5 mm/rev：

```text
320 / 0.5 = 640 pulse/mm
```

15 mm最大行程：

```text
15 × 640 = 9600 pulse
```

项目中所有上位机、固件、扫描规划和测试统一使用：

```text
PULSES_PER_MM = 640
TRAVEL_MM = 15.0
MAX_TRAVEL_PULSES = 9600
```

旧上位机中的 `800 pulse/mm` 和固件中的 `160000 max_steps` 不再使用。

## 4. 速度

统一初始范围：

```text
100～14000 pulse/s
默认 10000 pulse/s
```

10000微步脉冲/秒等于625全步/秒，低于图纸给出的最大启动频率900 pps。
14000微步脉冲/秒等于875全步/秒，作为首次实机验证上限。最终量产上限应以
15 mm全行程、带载、往返和重复扫描不失步为准。

固件必须在计算定时器 ARR 之前验证速度，禁止零除、无符号下溢或 `uint16_t`
环绕。

## 5. 引脚

### 5.1 STEP/DIR

| 轴 | STEP | DIR | 定时器 |
|---|---|---|---|
| X | PA8 | PA7 | TIM1 CH1 |
| Y | PA6 | PA5 | TIM3 CH1 |
| Z | PA0 | PA1 | TIM2 CH1 |

### 5.2 TMC和使能

- PA9：USART1 TX，115200、8N1；
- PB12：SPREAD；
- PB14：ENN，0使能、1禁用；
- PA3：旧DIAG输入，硬件无效，本次停用；
- PB10：原3.3V相关配置，不参与新限位。

### 5.3 机械零点限位

用户确认：

| 引脚 | 配置 | 作用 |
|---|---|---|
| PB3 | 输入上拉、下降沿 | X零点 |
| PB4 | 输入上拉、下降沿 | Y零点 |
| PB5 | 输入上拉、下降沿 | Z零点 |
| PB6 | 推挽输出0V | 三个开关公共参考 |

开关为常开触点：

```text
PB3 ─ X零点开关 ─┐
PB4 ─ Y零点开关 ─┼─ PB6（固定0V）
PB5 ─ Z零点开关 ─┘
```

语义：

- `1`：开关断开，未到零点；
- `0`：开关闭合，到达零点。

PB3/PB4 原JTAG功能已由 `__HAL_AFIO_REMAP_SWJ_NOJTAG()` 释放，PA13/PA14 SWD
保留。PB3占用EXTI3后不再使用PA3 DIAG。

常开接法不能识别断线。长线建议外部4.7～10 kΩ上拉和约100 nF滤波。

## 6. TMC2209初始化

当前初始化寄存器：

| 寄存器 | 值 | 作用 |
|---|---:|---|
| GCONF | `0x000000C4` | 通用配置 |
| GSTAT | `0x00000003` | 清状态 |
| IHOLD_IRUN | `0x00080F00` | 保持/运行电流 |
| CHOPCONF | `0x140100C3` | 斩波和16微步 |
| TPOWERDOWN | `0x00000014` | 掉电延迟 |

硬件只可靠支持向TMC2209写配置，不把驱动器读回或DIAG当作位置反馈。

## 7. 坐标边界

软件坐标固定为：

```text
0.0 <= position <= 15.0 mm
```

反向运动允许，但目标不得小于0。坐标是开环估算值，不是编码器测量值。

可信坐标可由以下方式建立：

1. 同一控制器正常关闭后的持久化恢复；
2. 用户确认当前位置；
3. 软件坐标清零；
4. 可选机械回零。

扫描前不强制机械回零。机械回零主要用于首次校准、坐标失效和异常恢复。

正向端没有机械限位。若在非机械零点执行软件清零，15 mm正向软限位不再代表
真实剩余机械行程，界面必须警告。

## 8. 零点限位与回零

限位触发分两层：

1. EXTI原始下降沿立即停止对应PWM；
2. 主循环确认低电平稳定约5～10 ms，再更新状态。

规则：

- 开关闭合时禁止继续朝零点运动；
- 允许反向离开开关；
- 短毛刺可以停止运动，但不能错误设置坐标0；
- 扫描中非预期触发会中止当前轮次；
- 显式回零中触发属于预期事件。

机械回零流程：

1. 若开关已闭合，先反向离开；
2. 快速朝零点接近；
3. 首次触发停止；
4. 退出约0.5 mm；
5. 低速二次接近；
6. 稳定触发后坐标设0；
7. 未在最大距离/时间内触发则失败。

初始固件语义中 `DIR_CCW=0` 为坐标减小方向。每轴真实极性必须在无负载或低速
实机测试中确认，并通过轴配置常量修正。

## 9. 扫描运动

参数：

- X轴行程 `x`；
- Y轴行程 `y`；
- 行程数 `n`；
- 扫描次数 `m`；
- X步数 `x_steps`；
- Y步数 `y_steps`；
- 步时 `dwell_s`。

每轮从当前 `(start_x,start_y)` 开始：

```text
方向 = +X
重复 n 次:
    X沿当前方向移动x
    Y沿+Y移动y
    X方向反转
最后再移动一次X
```

所以每轮：

- X移动 `n+1` 个完整行程；
- Y移动 `n` 次；
- 矩形为 `x × y*n`。

每个X行程拆成 `x_steps` 个 `x/x_steps` 子步，每个Y推进拆成 `y_steps`
个 `y/y_steps` 子步。每个子步明确完成后等待 `dwell_s`，最后一个子步后的等待
同时作为换轴等待。

路径预检：

```text
start_x + x <= 15
start_y + y*n <= 15
```

最后一次X完成后停止并保存本轮光谱采集，然后X/Y返回本轮起点；复位不采集、不分步、
不应用扫描步时。复位成功后才开始下一轮，共执行 `m` 轮。

## 10. 故障边界

步进电机堵转或失步时，脉冲计数仍可能正常结束，因此软件不能自动知道真实位置。

异常处理：

1. 停止电机；
2. 停止光谱采集；
3. 当前轮次标记未完成；
4. 坐标标记不可信；
5. 不盲目自动复位；
6. 使用低速短距离点动或机械回零恢复。

机械零点开关能重新建立零点，但不能检测正向端堵转、断线或任意位置失步。

## 11. 旧代码问题清单

- 旧上位机同时包含扫描、矩阵、激光器和数据处理，职责耦合；
- 旧上位机使用PySerial/Tkinter/Matplotlib，不适合作为目标界面；
- 旧上位机部分等待估算使用800 pulse/mm；
- 固件 `max_steps=160000` 与15 mm规格冲突；
- 固件速度没有可信上限；
- `RESET` 只停止电机，却描述成复位原点；
- SPEED成功响应没有正确复制到命令响应；
- STATUS临时缓冲区大于全局响应缓冲区；
- CDC命令按USB包处理，缺少跨包文本行缓冲；
- CDC忙时响应可能丢失；
- 固件扫描命令已禁用，扫描应由上位机统一控制；
- PA3 DIAG不可作为可靠堵转反馈。

## 12. 保证边界

软件可以保证：

- 命令、参数、累计软坐标和扫描规划不越界；
- 零点开关闭合时快速停止对应轴；
- 光谱采集和电机扫描按状态机互锁；
- 异常时保留数据并阻止盲目继续。

软件不能在现有硬件下保证：

- 自动检测所有堵转/失步；
- 检测常开限位线断线；
- 在没有正向机械开关时感知真实正端；
- 未经实机验证就确认三轴物理方向和最高无失步速度。

# LK-MD2202 主机侧验证记录

记录日期：2026-08-13。此记录只证明不接真实机构时可验证的主机代码，不代表
ROCK 4B+、RS-485 电气、方向、限位、距离、温升或负载验收。

## 已完成

- Modbus-RTU CRC、分帧、严格响应解析和异常响应测试；
- LK-MD2202 身份、寄存器、默认参数和 32 位高低寄存器测试；
- USB 串口候选枚举与只读协议身份确认；
- 读取可重试、动作不重试、紧急停止队列和有限关闭；
- X/M1、Y/M2 的 320 pulse/mm、软件零点、回零和行程保护；
- 电机设置弹窗、建议默认值、固定零点限位和参数差异摘要；
- `n+1` 次 X、`n` 次 Y、整数脉冲子步、步时、多轮采集/保存/返回；
- 扫描占用、停止与故障清理；
- ROCK 4B+ 部署源码镜像检查。
- LK-MD2202速度控制寄存器的正数、负数、0和int32边界编码；
- “设速”取绝对值、“脱离卡死”保留方向符号的会话语义；
- 限位闭合→断开提前停止、错误方向断开→闭合停止和1秒/4800 pulse双重截止；
- 机械回零必须观察本次断开→闭合，并使用2～5秒动态超时；
- 速度0、位置急停、停止回读、停止未知锁定和两轴停止后解锁；
- 空闲500 ms状态轮询、三态限位显示、`ttyFIQ*`排除和连接状态栏结束提示；
- 停止未知只锁定电机与扫描，不锁定独立光谱仪采集。

本轮定向自动化结果：电机与主窗口相关测试 `138 passed`。完整回归和部署镜像结果
在生成本轮 ROCK 4B+ 部署副本后更新；定向测试不能替代板端实机运动验收。

## 当前验证环境

- Windows 测试解释器：Python 3.9.13；
- 当前可用兼容 Qt：PyQt5；
- 产品依赖与部署目标：PyQt6；
- PyQt6 必须在 ROCK 4B+ 或单独的 PyQt6 环境再次运行全部测试和界面冒烟测试。

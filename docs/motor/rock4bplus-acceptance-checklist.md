# ROCK 4B+ + LK-MD2202 实机验收清单

所有运动从无负载或安全位置、短距离和可立即断电的条件开始。速度使用已经实测能
平稳运行的值；当前机构以10000 pps为首选，不假设越低越安全。未现场完成的项目保持未勾选。

## A. 环境与回退

- [ ] 系统为 Debian 12 Bookworm ARM64；
- [ ] Python 为 3.11，实际 Qt 绑定为 PyQt6，QtSerialPort 可导入；
- [ ] 当前提交号、部署包 SHA-256 和安装日期已记录；
- [ ] `backup/pre-lk-md2202-20260810` 标签可用于回退；
- [ ] 原光谱仪采集、保存、历史、诊断功能仍可运行；
- [ ] 活动流程不要求编译或烧录 STM32 HEX。

## B. 接线与无运动只读检查

- [ ] ROCK 4B+、USB-RS485、LK-MD2202 共地且供电正确；
- [ ] X 接 M1，Y 接 M2；
- [ ] X 开关接 M1-K/GND，Y 开关接 M2-K/GND；
- [ ] 开关断开时限位无效，闭合接地时仅对应轴限位有效；
- [ ] 普通用户属于 `dialout`，无需 `sudo` 可打开串口；
- [ ] `lsusb`、`lsusb -t`、`udevadm info` 和稳定设备路径已保存；
- [ ] `python -m spectrometer.motor.probe --json` 只读成功；
- [ ] 探针未产生电机运动、回零、停止或参数写入。
- [ ] 自动候选中不出现 `ttyFIQ0`或其他`ttyFIQ*`板载调试串口；
- [ ] 自动识别成功、失败和断开后状态栏不再停留在“正在识别电机串口……”。

## C. 驱动板配置

- [ ] 身份严格读回 `LK-MD2202`；
- [ ] 地址 1、9600 baud、8N1、无校验；
- [ ] 两轴均为 1.8°、8 细分、50% 电流、零点限位；
- [ ] 两轴终点均为 4800 pulse，停止电流无锁定；
- [ ] 两轴加速/减速/位置速度均为 10000；
- [ ] 参数差异确认后只写变化字段；
- [ ] 写入后完整回读一致才显示成功；
- [ ] 地址或波特率修改后能用新参数重新连接；
- [ ] 运动或扫描期间参数写入被拒绝。

## D. 方向、限位与机械回零

- [ ] X/M1 正反方向与界面一致，方向反转设置已记录；
- [ ] Y/M2 正反方向与界面一致，方向反转设置已记录；
- [ ] LK-MD2202 的 X 回零方向确实朝 X 零点；
- [ ] LK-MD2202 的 Y 回零方向确实朝 Y 零点；
- [ ] X 限位只停止/约束 X，Y 限位只停止/约束 Y；
- [ ] 开关闭合时可安全离开零点；
- [ ] 速度框输入负数后，“设速”写入绝对值，正常定距运动速度保持正值；
- [ ] X“脱离卡死”正负速度方向、写速度0停止和急停均已验证；
- [ ] Y“脱离卡死”正负速度方向、写速度0停止和急停均已验证；
- [ ] 初始限位闭合时，脱离卡死在限位释放后提前停止；
- [ ] 初始限位断开且朝零点运动时，闭合限位后立即停止并提示方向风险；
- [ ] 10000 pps单次脱离不超过约0.48秒，5000 pps不超过约0.96秒，任何速度不超过1秒；
- [ ] 回零开始时限位已经闭合会被拒绝，并提示先执行脱离卡死；
- [ ] 限位始终不闭合时，机械回零在2～5秒动态超时内急停且不校准；
- [ ] 单轴机械回零实际观察到“断开→闭合”，最终停止、累计位置0和限位闭合后才显示已校准；
- [ ] 双轴机械回零按 X、Y 顺序完成；
- [ ] 扫描前不强制回零，未校准扫描会显示风险确认。

## E. 距离、坐标和异常

- [ ] 1 mm 命令为 320 pulse，15 mm 命令为 4800 pulse；
- [ ] X/Y 的 1、5、15 mm 实际距离在允许误差内；
- [ ] 已校准时目标小于 0 或大于 4800 pulse 被拒绝；
- [ ] 软件清零不产生运动；
- [ ] 软件坐标可以为负；
- [ ] 软件回零返回本次会话的软件 0 点；
- [ ] 重启后不恢复软件零点或校准状态；
- [ ] 模拟卡滞/掉步后操作员能停止并重新建立可信坐标；
- [ ] 电机断线、超时或结果未知不会自动重发运动命令。
- [ ] 驱动器累计脉冲变化未被当作电机真实位移的唯一证据；
- [ ] 停止结果未知时手动运动、回零、脱离卡死和扫描均被锁定；
- [ ] “清除故障”不能绕过停止确认；两轴均回读停止后才能解锁；
- [ ] RS-485断开且无法确认停止时，界面明确提示切断驱动板电源；
- [ ] 断开重连后速度框恢复驱动板正数速度，不保留上次会话负号。
- [ ] 任一手动电机动作结束后，“X行程”及其他扫描输入框不会被自动选中；
- [ ] 脱离卡死停止后的第一次运行状态仍为“运行中”时，会补发急停并复核，不立即误锁；
- [ ] 脱离卡死确认停止后保持未校准，并可直接重新机械回零而无需重连；
- [ ] 持续运行或持续无法读取停止状态时仍进入安全锁。
- [ ] 单次运动状态查询偶发超时不会结束当前运动，也不会提前启动下一轴；
- [ ] 状态查询恢复后，只有“已停止且累计位置与目标一致”才确认运动成功；
- [ ] 状态查询持续失败或整段运动超时仍触发停止确认，结果未知时保持安全锁。

## F. 扫描路径

- [ ] `x=10,y=1,n=10,m=2` 每轮执行 11 次 X、10 次 Y；
- [ ] X 方向交替，Y 始终正向推进；
- [ ] 每轮扫描结束后返回同一起点；
- [ ] X/Y 步数默认 1，步时默认 0；
- [ ] 非整除子步按整数脉冲分配且总脉冲不变；
- [ ] 相邻子步及换轴处只等待一次步时；
- [ ] 已校准路径不会超过两轴 15 mm 行程；
- [ ] 未校准路径经用户确认后可启动；
- [ ] 返回失败不会开始下一轮。
- [ ] 未连接光谱仪时“开始扫描”可以执行完整纯电机扫描与每轮返回；
- [ ] 纯电机扫描不启动、停止或重置光谱仪采集；
- [ ] 纯电机扫描不生成独立 `scan-*.json`，参数、轮次和结果写入当前诊断日志；
- [ ] 纯电机扫描后的“导出诊断包”优先导出本次运行日志；
- [ ] 纯电机扫描的用户停止、限位故障和电机断线不会等待不存在的光谱仪任务。
- [ ] 步时为0时连续执行至少3轮相同参数纯电机扫描，换轴间无约1秒阶梯式停顿；
- [ ] 相邻轴绝不重叠运动，前一轴停止和目标位置确认后才发送后一轴命令；
- [ ] 偶发状态读取失败只造成短暂重新查询，不产生一次完整串口超时重试阶梯。

## G. 光谱仪联动与故障

- [ ] 每轮第一段运动前只启动一次连续采集；
- [ ] 子步、步时和换轴期间持续采集；
- [ ] 最后一段 X 后停止并完成保存，再无采集返回起点；
- [ ] `m=2` 生成两轮独立数据与清单；
- [ ] 用户停止同时停止电机与光谱采集；
- [ ] 电机掉线、限位异常、运动失败会中止当前轮；
- [ ] 光谱仪启动、采集或保存失败会停止电机；
- [ ] 中止轮标记未完成且不盲目自动复位；
- [ ] 无激光器控制调用，无旧“数据处理”调用；
- [ ] 普通光谱仪单次/连续采集行为无变化。
- [ ] 电机停止未知锁定期间，独立光谱仪采集仍可使用。

## H. 性能与软件验证

- [ ] GUI 线程不被电机串口或步时阻塞；
- [ ] 光谱完整帧持久化计数无下降；
- [ ] 热拔插后串口和线程正常释放；
- [ ] 长时间多轮扫描 CPU、内存和磁盘稳定；
- [ ] `python -m compileall -q main.py spectrometer tools` 通过；
- [ ] `python -m pytest -q` 通过；
- [ ] `python tools/build_rock4bplus_deploy.py --check` 通过；
- [ ] 诊断中记录实际 Qt 绑定、电机事件、扫描状态和停止原因。
- [ ] 每段运动只有一条完成摘要，包含耗时、状态查询次数、读取失败次数、结果和原因；
- [ ] 对照诊断包确认现场换轴延迟不再随单次丢帧增加约1秒。

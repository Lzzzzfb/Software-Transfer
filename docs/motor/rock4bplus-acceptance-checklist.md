# ROCK 4B+ 电机与光谱扫描验收清单

## A. 固件构建与回退

- [ ] Keil/CubeIDE全量构建无错误；
- [ ] 构建日志已保存；
- [ ] 原始HEX和新HEX均保留；
- [ ] 两个HEX记录SHA-256；
- [ ] 已验证可以重新烧录原始HEX；
- [ ] 固件协议版本与上位机版本匹配。

## B. 上电前电气检查

- [ ] 机械负载暂时断开或处于安全位置；
- [ ] PB6为0V且运行时不会输出3.3V；
- [ ] PB3/PB4/PB5开关断开时为高电平；
- [ ] 三个开关闭合时相应输入为低电平；
- [ ] PB3/PB4/PB5没有5V或12V；
- [ ] PA13/PA14 SWD下载仍可用；
- [ ] PA3 DIAG已停用。

## C. 限位和回零

- [ ] X开关闭合只停止X；
- [ ] Y开关闭合只停止Y；
- [ ] Z开关闭合只停止Z；
- [ ] 开关闭合时不能继续朝零点移动；
- [ ] 开关闭合时可以离开零点；
- [ ] 毛刺不会把坐标错误设置为0；
- [ ] 单轴回零执行快速接近、退出、慢速二次接近；
- [ ] X/Y/Z真实回零方向已确认；
- [ ] 回零超时和开关故障会安全停止；
- [ ] 扫描前不会被强制要求回零。

## D. USB与自动识别

- [ ] ROCK 4B+识别VID:PID `0483:5740`；
- [ ] MCU USB序列号可读取且稳定；
- [ ] udev权限为dialout/0660/uaccess；
- [ ] 普通用户无需sudo即可打开端口；
- [ ] `ID?`返回`ID=TMC2209`和`MOTOR_PROTOCOL=2`；
- [ ] 不会把光谱仪串口识别为电机；
- [ ] 热拔插后界面状态和线程正常释放；
- [ ] 运动命令超时不会自动重发。

## E. 基础运动

- [ ] X/Y/Z速度范围100～14000；
- [ ] 默认速度10000；
- [ ] 1 mm对应640脉冲；
- [ ] 1/5/15 mm距离实测；
- [ ] 正反方向与界面一致；
- [ ] 软件坐标限制为0～15 mm；
- [ ] 负目标被拒绝；
- [ ] 超过15 mm目标被拒绝；
- [ ] 软件清零不产生运动；
- [ ] 软件回零返回软件坐标0；
- [ ] 正常关闭后同一控制器坐标可以恢复；
- [ ] 异常断电或运动中断开后坐标标记不可信。

## F. 扫描路径

- [ ] `x=10,y=1,n=10`执行11次X和10次Y；
- [ ] X方向交替；
- [ ] Y始终正向推进；
- [ ] 奇数和偶数n终点正确；
- [ ] X步数默认1；
- [ ] Y步数默认1；
- [ ] 步时默认0；
- [ ] X子步为x/x_steps；
- [ ] Y子步为y/y_steps；
- [ ] 每个子步完成后等待一次；
- [ ] 换轴不重复等待；
- [ ] 起点+x不超过15；
- [ ] 起点+y*n不超过15；
- [ ] 每轮结束返回同一起点；
- [ ] 复位失败不会开始下一轮。

## G. 光谱采集联动

- [ ] 每轮第一段X之前启动一次连续采集；
- [ ] 等待采集确认后才移动电机；
- [ ] 子步和步时期间持续采集；
- [ ] 最后X完成后停止一次采集；
- [ ] 等待尾帧和封存完成后才复位；
- [ ] 复位期间不采集；
- [ ] `m=2`生成两组轮次数据；
- [ ] 每轮清单包含参数、设备身份、文件和状态；
- [ ] 普通光谱采集流程无变化；
- [ ] 背景、参考、校准和手动保存无回归；
- [ ] 没有激光器调用；
- [ ] 没有旧数据处理调用。

## H. 故障

- [ ] 用户停止同时停止电机和光谱采集；
- [ ] 限位触发中止当前轮次；
- [ ] 电机USB断开中止当前轮次；
- [ ] 光谱仪失败停止电机；
- [ ] 电机超时停止光谱采集；
- [ ] 中止轮次标记未完成；
- [ ] 中止不自动盲目复位；
- [ ] 恢复spool被保留；
- [ ] 运动异常会自动使软件坐标失效；
- [ ] 故障清除不会自动恢复坐标；
- [ ] 应用退出有限等待并安全关闭。

- [ ] 光谱完整帧持久化计数无下降；

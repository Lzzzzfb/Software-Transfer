# 实机联调与发布环境待验证清单

状态：代码侧工作已完成；以下项目必须连接真实光谱仪或安装正式发布环境后逐项核验。

## 1. 协议和连接

- 核对 `0x01` 版本响应在不同固件上的实际长度（32/40 字节）和字段值。
- 核对所有设置指令 ACK 的成功值为 `0x6x`、失败值为 `0x7x`。
- 抓取至少一帧真实 `0x80` 原始字节，核对 U32 包号、保留低 8 位、像素大端序和 `nLength=6+2*N`。
- 确认下位机数据校验字节确实无需数值验证，只需消费。
- 拔插 USB/串口，验证断线状态、端口保留和退避重连。

## 2. 参数与校准

- 查询并设置积分时间、触发模式、间隔、平均次数、增益和延时，确认只有 ACK 后界面值生效。
- 用已知波长点验证现有 `C4,C3,C2,C1` 收发反序逻辑，禁止调整当前正确校准系数算法。
- 验证 2048/4096 像素及非零起始像素设备的裁剪范围。

## 3. 采集与同步

- 单台单次、连续和外触发采集。
- 多台软件同步。
- 内部硬同步：从机先布防、主机最后启动；确认下位机自动输出同步脉冲。
- 外部硬同步：所有设备只布防、等待外部信号。
- 确认上位机不需要为每帧发送 `0x54`。
- 4 台设备、每台 4096 像素、100 fps 持续压力测试，核对下位机包序号、缓存记录和导出列数完全一致。

## 4. 处理和存储

- 使用真实暗场和参考场核对扣背景与吸光度。
- 使用不同设备、不同波段和不同像素数同时采集，核对 Excel 独立工作表及各自波长列。
- 默认 500 帧批次分别打开 CSV 和 Excel，抽查首、中、末帧代表像素。
- 人为占用 Excel 文件、断开磁盘或制造空间不足，确认错误可诊断且 `.part` 保留。
- 异常结束后运行恢复流程，核对完整帧数和截断尾记录报告。

## 5. 64 位发布

- 当前开发机没有 PySide6，尚未实际执行 PyInstaller；需在 Python 3.12 64 位正式环境运行 `python -m PyInstaller --clean --noconfirm spectrometer.spec`。
- 在干净 Windows 10/11 64 位机器确认 Qt 平台插件、Qt SerialPort、CSV/Excel、中文路径和安全退出。
- 确认程序关闭后无残留串口线程、存储线程或 `.part`（存在导出错误时除外）。

联调时建议把原始串口日志、设备型号/固件版本和对应导出文件放在不提交 Git 的 `data/validation/` 下。

# PySide6 自动识别与三机实机联调报告（2026-07-22）

## 结论

已在项目 `.venv` 的 Python 3.13.7 64 位、PySide6 6.11.1 环境完成 COM10、COM14、COM17、COM18 同时扫描验证。COM10 虽与光谱仪使用相同 USB 串口 VID/PID，但不响应上位机版本查询，握手超时后被关闭并排除；COM14、COM17、COM18 均被正确识别、初始化并完成连续采集、实时绘图和批量 CSV/Excel 导出。

## 原因与修复

- PySide6 无法为 `Q_ARG(bytes, ...)` 建立 Qt 元类型，串口线程因此没有收到上位机命令。跨线程载荷已统一改为 `QByteArray`。
- “串口能够打开”不再等同于“光谱仪已连接”。端口打开后先发送 `GET_VERSION(0x01)`，只有返回字段和像素范围合法的版本帧才会加入设备列表。
- 无响应候选端口在 2.5 秒后关闭并进入 30–300 秒递增退避；手动连接可立即强制重试。
- 采集和存储只接受已通过握手且初始化完成的设备。

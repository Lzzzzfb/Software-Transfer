# Radxa ROCK 4B+ Linux 迁移设计

日期：2026-07-27  
状态：已获用户确认，等待书面规格复核

## 1. 目标

将当前工作区中的光谱仪软件迁移为 Radxa ROCK 4B+ Linux 专用版本。目标运行环境为 Debian 12 Bookworm ARM64、Python 3.11，以源码和虚拟环境运行。

第一阶段使用一台 CH569W 光谱仪完成正式验收，覆盖：

- 自动识别；
- 协议握手；
- 参数读取；
- 实时曲线；
- 采集停止；
- CSV 和 Excel 保存；
- 断线重连。

当前工作区与原 Windows 项目分开维护。本迁移不得修改 `D:\codex\光谱仪`。

## 2. 受保护内容和实施边界

当前分支为 `main`。设计检查时唯一未提交文件为：

```text
CCD_CMOS模块采集卡(下位机)函数表20251027.xlsx
```

该 Excel 文件属于用户已有修改。后续不得覆盖、删除、还原、复制到部署目录、暂存或提交该文件。

实施仅允许修改：

```text
D:\codex\光谱仪 - Linux转移版
```

写入操作不得扩展到原 Windows 项目或用户提供的 ROCK 4B+ 产品简介目录。

## 3. 技术方案选择

采用“Linux 专用适配、保留 Qt SerialPort 架构”方案：

- 复用现有协议解析、设备模型、采集状态机、绘图、存储和缓存恢复逻辑；
- 定向替换设备发现、运行环境、配置路径、字体、部署和 Linux 错误处理；
- 不将本副本继续设计为 Windows/Linux 共用源码；
- 不以 pyserial 重写现有串口线程。

### 3.1 Qt 绑定选择

Debian 12 ARM64 的 glibc 版本为 2.36，而 PyPI 当前提供的 PySide6 Linux ARM64 wheel 要求 glibc 2.39 或更高。Debian 12 官方仓库没有对应的 PySide6 包，但提供 Python 3.11、PyQt6 和 PyQt6 QtSerialPort。

因此板端运行时采用 Debian 官方 PyQt6：

- Qt Widgets 和 `QSerialPort` 架构不变；
- Linux 专用兼容层优先导入 PyQt6；
- 不从源码编译 PySide6；
- 不升级到 Debian 13；
- Windows 原项目不受此选择影响。

参考：

- https://pypi.org/project/PySide6/
- https://packages.debian.org/bookworm/arm64/libc6
- https://packages.debian.org/bookworm/arm64/python3-pyqt6
- https://packages.debian.org/bookworm/arm64/python3-pyqt6.qtserialport

## 4. 总体架构

迁移后的系统保留四层边界。

### 4.1 业务核心

继续复用：

- CH569W 命令构造与响应解析；
- 两种实机数据帧格式兼容；
- U16LE/U32LE 包号兼容；
- U16BE 像素解析；
- 设备参数、校准和生产序列号模型；
- 采集控制和冲突防护；
- 实时处理和曲线显示；
- CSV、Excel、后台导出和 `.part` 恢复。

只修复迁移实际需要的兼容问题，不进行无关重构。

### 4.2 Linux 设备接入层

继续使用 Qt SerialPort。设备发现严格匹配 USB VID:PID `1a86:fe0c`，随后通过光谱仪协议握手确认设备身份。

### 4.3 Linux 运行环境层

- Python 3.11；
- Debian 12 ARM64；
- 用户配置目录：`~/.config/ZGCAI/Spectrometer/`；
- 默认采集目录：`~/ZGCAI-Spectrometer-Data/`；
- Debian 常见中文字体优先，系统默认字体回退；
- 界面以 1920×1080 为基准；
- 1366×768 作为基本可操作性兼容检查目标。

### 4.4 板端部署层

安装位置：

```text
/opt/zgcai-spectrometer
```

程序和 venv 位于 `/opt`，配置、日志和采集数据位于当前用户主目录。日常运行不得要求 `sudo`。

## 5. 设备发现和身份

### 5.1 VID:PID 的含义

`1a86:fe0c` 标识一类 CH569W USB 设备，不唯一标识某一台物理光谱仪。多台同型号设备可能共享相同 VID:PID。

因此身份识别分两层：

1. VID:PID 筛选候选串口；
2. 协议握手和生产序列号确认并区分光谱仪。

### 5.2 枚举规则

- 扫描全部匹配 `1a86:fe0c` 的 `/dev/ttyACM*`；
- 不再使用宽泛的常见 USB 串口 VID 或描述关键字作为正式候选条件；
- 每个候选端口必须通过版本查询握手；
- 串口能打开但握手失败时，关闭并按退避策略稍后重试；
- 同一当前端口不得创建重复 worker；
- 同一生产序列号不得创建重复设备连接。

### 5.3 生产序列号异常

正常情况下，以协议返回的生产序列号作为物理设备身份。

若生产序列号为空或重复：

- 设备仍可显示；
- 界面和诊断日志必须标记身份冲突；
- 记录当前 tty 路径和 USB 拓扑信息；
- 不得静默合并两台设备。

第一阶段正式验收使用一台设备，但设备发现设计不得人为限制为只能识别一台。

## 6. udev 和串口权限

udev 规则仅匹配 `1a86:fe0c`，用于：

- 设置 `dialout` 组读写权限；
- 触发标准设备权限刷新；
- 支持普通用户运行。

不得创建所有同型号设备共享的 `/dev/zgcai-spectrometer` 软链接，因为多台设备会发生名称冲突。

安装脚本将当前用户加入 `dialout` 组，并明确提示注销后重新登录、重新插拔设备。若 USB 层提供可靠的唯一序列号，可以使用 `/dev/serial/by-id/` 作为辅助诊断信息，但不得假设所有 CH569W 都提供该信息。

## 7. 握手和初始化

连接状态流为：

```text
未发现
→ 发现匹配 VID:PID 的 ttyACM 设备
→ 打开串口
→ 发送版本查询
→ 校验设备信息和像素范围
→ 查询校准、生产序列号和运行参数
→ 就绪
```

规则：

- 启动时没有设备不构成致命错误，界面显示等待设备；
- 串口打开后在 2.5 秒内完成现有版本响应握手；
- 版本响应必须通过长度、版本数值、像素总数、起始像素和有效像素校验；
- 握手成功后按确定顺序读取版本、波长校准、生产序列号、触发模式、积分时间、平均次数、增益、延时等现有参数；
- 初始化完成前禁止开始采集；
- 初始化失败时不得将设备显示为就绪。

## 8. 断线和重连

### 8.1 断开处理

串口资源错误或设备从扫描结果中消失时：

- 立即标记设备离线；
- 停止接收新帧；
- 清除正在采集和正在初始化状态；
- 通知采集与存储状态机安全收尾；
- 保持 GUI 可操作；
- 记录断开原因、旧 tty 路径和时间。

### 8.2 重新发现

重连结合定时扫描和指数退避：

- 不继续死守旧 `/dev/ttyACM*`；
- 对新出现的匹配端口重新执行协议握手；
- 读取生产序列号后关联回已有物理设备；
- 防止扫描任务和重连任务创建重复 worker；
- 重连成功后重新读取必要参数；
- 不沿用旧连接的初始化状态。

重连后设备回到就绪状态，不自动恢复采集。断线前后的数据属于不同采集会话。

## 9. 实时采集和停止

数据流为：

```text
CH569W 数据帧
→ 串口线程解包
→ 帧序号和像素校验
→ 采集协调器
→ 实时曲线限频显示
→ 完整帧存储队列
```

要求：

- 串口读取、协议解包、绘图和文件导出保持异步；
- 实时曲线最高约 30 FPS；
- 显示限频不得丢弃存储链路中的完整帧；
- 采集前必须完成握手和必要参数读取；
- 停止时发送现有停止命令并处理 ACK 和尾帧；
- GUI 不等待 CSV/Excel 写盘完成；
- 停止超时、拔线或串口错误均须释放采集状态；
- 正常停止后保存不足一个完整批次的尾批。

## 10. CSV、Excel 和缓存

- 默认同时保存 CSV 和 Excel；
- CSV 和 Excel 均保持每帧一列、每像素一行；
- 保留 Pixel 和 Wavelength 列；
- Excel 使用每台设备独立工作表；
- 后台导出不得阻塞 GUI；
- 默认输出目录为 `~/ZGCAI-Spectrometer-Data/`；
- 用户可修改输出目录；
- 文件名继续使用当前简化规则；
- 已存在目标文件时增加顺序后缀，绝不覆盖；
- 导出过程中继续使用 `.part` 缓存；
- 导出失败时保留可恢复缓存并报告原因。

示例：

```text
20260727_SN001_B0001.csv
20260727_SN001_B0001.xlsx
```

断线时：

- 已完整接收的帧继续完成收尾；
- 不伪造缺失帧；
- 不将重连后的帧追加到断线前批次；
- 不完整缓存按现有恢复机制保留。

## 12. 安装脚本

`install.sh` 执行以下步骤：

1. 校验 ARM64、Debian 12、Python 3.11 和磁盘空间；
2. 通过 apt 安装 Python、venv、PyQt6、PyQt6 QtSerialPort、Qt/XCB/OpenGL 运行库和 Noto CJK 字体；
3. 将运行文件复制到 `/opt/zgcai-spectrometer`；
4. 使用 `python3 -m venv --system-site-packages` 创建 `.venv`；
5. 从 `requirements-rock4bplus.txt` 安装 NumPy、SciPy、XlsxWriter 和 openpyxl；
6. 安装并重新加载 udev 规则；
7. 将当前用户加入 `dialout`；
8. 安装 XDG 应用菜单项；
9. 根据当前用户的 XDG Desktop 目录创建桌面快捷方式；
10. 执行依赖导入自检。

PyQt6 由 apt 管理，不列入 pip 依赖清单。

安装任一步失败时立即停止并显示原因。只有全部自检成功后才安装最终快捷方式。

## 13. 启动方式

第一阶段只支持手动启动：

- 应用菜单；
- 桌面快捷方式；
- 命令行执行 `run.sh`。

不配置 systemd 服务，不设置开机自启。

`run.sh` 必须：

- 从 `/opt/zgcai-spectrometer` 启动；
- 使用 `/opt/zgcai-spectrometer/.venv/bin/python`；
- 创建用户配置、日志和数据目录；
- 将启动错误写入用户日志目录；
- 不使用 `sudo`；
- 不修改系统 Python。

# ROCK 4B+ 采集保存隔离与错帧保护设计

## 目标

解决 ROCK 4B+ 开启自动保存后界面卡顿、停止保存耗时较长，以及串口接收受阻后出现错误光谱帧的问题，同时保证实时曲线和导出文件采用一致的数据处理口径。

本设计只适用于 Linux 专用副本。第一阶段仍只验收单台 CH569W 光谱仪。

## 已确认行为

- 采用独立 Python 工作进程生成 CSV 和 Excel。
- 停止采集应立即作用于设备，文件可以继续在后台生成。
- 原始帧的有效性判断发生在背景扣除及其他光谱处理之前。
- 选择背景扣除时，实时曲线和导出文件都使用扣除后的结果。
- 背景扣除模式只导出处理结果，不额外保存原始强度列。
- 背景扣除产生的负数按浮点数保留，不截零、不转换为 U16。
- 不用单一强度阈值判定错帧，避免误删真实的暗光谱、饱和光谱或背景扣除结果。

## 性能约束

Qt 主进程不得承担全部采集帧的 Excel 生成或复杂统计工作。

- 串口接收路径只做协议长度、像素数量和序号等轻量检查。
- 绘图继续限速到 20 FPS，只处理当前显示所需的最新帧。
- 自动保存所需的逐帧处理、可疑帧分析和文件生成在独立进程执行。
- 保存进程使用有界任务队列；不能无限占用内存。
- Linux 保存进程降低调度优先级，优先保证串口接收和界面响应。

## 数据流

1. `QSerialPort` 接收 CH569W 字节流，拆出完整协议帧。
2. 主进程检查协议长度、像素数量和帧序号。
3. 原始不可变帧写入恢复用 `.part` 文件，并提交到有界保存队列。
4. 绘图定时器取最新原始帧，使用采集开始时冻结的处理上下文计算显示值。
5. 独立保存进程使用同一处理算法和同一份冻结上下文处理每个待保存帧。
6. 保存进程先排除确定错误的帧，再把处理结果写入 CSV/Excel。
7. 文件完成后，主进程接收结果通知并更新界面；所有输出成功后删除 `.part`。

“同一份处理结果”指绘图和导出使用相同算法、模式、背景、参考和强度校准快照。为避免主进程处理所有帧，两条路径不共享同一个内存数组，但对同一原始帧应产生数值一致的结果。

## 处理上下文

采集任务开始时冻结以下内容：

- 处理模式；
- 背景光谱；
- 参考光谱；
- 强度校准系数；
- 波长数组；
- 自定义公式及相关处理参数。

采集过程中修改界面选项只影响下一次任务，不能改变当前批次的计算口径。导出元数据记录处理模式、设备序列号和背景/参考是否启用。

## 帧保护

### 确定错误

满足下列任一可靠条件的帧不得进入曲线或最终导出：

- 协议帧长度无效；
- 像素数量与设备参数不一致；
- 在确认 CH569W 数据帧校验规则后，校验码不匹配；
- 数据无法按完整 U16 像素序列解析。

### 序号异常

序号重复、回退或跳变记录到诊断日志。序号跳变表示发生丢帧，但不能单独证明当前帧内容错误，因此不单独触发丢弃。

### 光谱统计异常

统计判断只针对背景扣除前的原始 U16 光谱。接近零、接近饱和或整体强度变化不能单独触发丢弃。

只有同时呈现多项错位特征，例如全量程盐胡椒跳变、相邻像素不连续性剧增、与滚动基线结构严重不一致并伴随接收异常时，才标记为确定错误。证据不足的帧标记为“可疑”，保留数据并写入诊断信息，避免误删真实光谱。

阈值必须通过已传回的 B0001 正常数据和 B0002 异常数据建立测试，不直接写死未经验证的绝对光强范围。

## 独立保存进程

保存进程接收可序列化的批次描述和冻结处理上下文，不依赖 Qt 对象。进程负责：

- 从恢复数据读取原始帧；
- 运行光谱处理和错帧统计；
- 写入临时目标文件；
- 原子替换为最终 CSV/XLSX；
- 返回输出文件、帧计数、丢弃帧及错误信息。

CSV 与 Excel 保持现有“每列一帧”的布局。处理结果使用浮点格式。保存进程异常退出时不删除 `.part`，最终目标文件也不能以半成品形式出现。

## 停止与界面状态

用户点击停止后，设备停止命令优先发送，不等待 CSV/Excel 完成。任务状态区区分：

- 正在采集；
- 已停止，正在后台保存；
- 保存完成；
- 保存失败，可恢复。

应用正常退出时等待一个有限时间；若保存仍未完成，保留 `.part` 并明确提示，不静默丢失数据。

## 背压和故障降级

- 保存队列达到 50% 时记录警告。
- 达到 90% 时请求受控停止采集。
- 队列满时保留已经写入 `.part` 的帧并停止继续采集。
- 工作进程失败、磁盘写满或目标文件生成失败时，界面报告具体错误并保留恢复文件。
- 独立进程不可用时不退回到主线程执行大型 Excel 导出，以免重新引入界面冻结。

## 测试与验收

自动化测试覆盖：

- 背景扣除后的负值原样进入 CSV 和 Excel；
- 绘图与导出对同一帧产生一致结果；
- 采集开始后处理上下文保持不变；
- B0001 不被误判；
- B0002 已确认的错位帧能被识别，序号跳变得到记录；
- 暗光谱、整体饱和和正常快速强度变化不因单阈值被误删；
- 保存运行时 Qt 事件循环保持响应；
- 停止采集不等待文件导出；
- 工作进程失败时 `.part` 保留且半成品不暴露；
- 完整测试套件通过。

实机复验覆盖自动识别、握手、参数读取、连续采集、背景扣除曲线、停止、CSV/Excel、异常诊断和断线重连。复验时同时观察主进程 CPU、保存进程 CPU、帧序号和界面响应。

## 修改范围

只修改 `D:\codex\光谱仪 - Linux转移版`。不修改原 Windows 项目，不覆盖或删除当前未提交的 Excel 文件，也不改写传回的实机验证数据。

完成实现和测试后重新生成 `deploy/rock4bplus`，部署目录仍只包含板端运行文件、依赖清单、安装脚本、启动脚本、udev 规则和桌面快捷方式。

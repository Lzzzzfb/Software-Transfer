# 采集表格文件命名简化设计

日期：2026-07-24

## 目标

简化自动采集生成的 CSV 和 Excel 文件名，只保留采集日期、设备生产序列号或“多设备”标识，以及批次号。

## 命名格式

设备 CSV：

```text
YYYYMMDD_SN序列号_B批次号.csv
```

多设备 Excel：

```text
YYYYMMDD_多设备_B批次号.xlsx
```

单机 Excel：

```text
YYYYMMDD_SN序列号_B批次号.xlsx
```

示例：

```text
20260724_SN001_B0001.csv
20260724_SN002_B0001.csv
20260724_SN003_B0001.csv
20260724_多设备_B0001.xlsx
```

## 明确删除的文件名信息

- 不包含时、分、秒。
- 不包含独立采集、软件同步、硬同步、单机连续或单机单次等采集模式。
- 不包含 COM 串口号。

设备端口、同步方式、积分时间等信息仍可保留在 CSV/Excel 的内部元数据中，本次只改变文件名。

## 缺失序列号与防覆盖

- 能读取生产序列号时统一使用 `SN` 前缀；设备返回 `001` 时文件名使用 `SN001`。
- 生产序列号为空时使用稳定的当前设备编号，例如 `设备0`，不使用串口号。
- 文件已存在时不覆盖，依次增加 `_01`、`_02`：

```text
20260724_SN001_B0001_01.csv
20260724_多设备_B0001_01.xlsx
```

- `B0001`、`B0002` 等批次编号规则保持不变。

## 范围

本次只修改自动采集生成的 CSV/Excel 表格命名。以下文件不变：

- 手动保存的光谱图片；
- 缓存恢复生成的文件；
- 内部 `.part` 恢复缓存；
- 背景和参考 JSON。

## 验证

- 全局三设备采集生成三个按序列号命名的 CSV 和一个“多设备”Excel。
- 单机采集生成相同主体名称的 CSV/Excel。
- 文件名中不存在时分秒、采集模式和 COM 串口号。
- 同名文件自动增加两位防覆盖序号。
- 表格内部设备、端口、同步方式和批次元数据保持完整。
- 命名、存储及全量自动测试通过。

# “打开文件”按钮文字调整设计

日期：2026-07-23

## 目标

将主窗口顶部工具栏中的“打开历史”按钮改为“打开文件”，使按钮名称直接表达选择已有数据文件的动作。

## 范围

- 只修改主窗口顶部按钮的显示文字：“打开历史”改为“打开文件”。
- 历史数据页内部的“打开 CSV / Excel”按钮保持不变，用于明确提示支持的文件类型。
- 点击顶部按钮后仍切换到“历史数据”页并打开文件选择窗口。
- 不修改 CSV、Excel 的解析规则，不修改历史曲线数量限制，也不修改缓存恢复功能。

## 文件识别规则

- CSV 会查找首列内容为 `Pixel` 的表头行；A/B 列为 Pixel/Wavelength，C 列起为光谱帧。
- Excel 跳过“采集概要”页；其他数据工作表的第一行须以 `Pixel` 开头，A/B 列为 Pixel/Wavelength，C 列起为光谱帧。
- 程序自动读取所选文件中符合上述规则的设备工作表和帧，但不推断任意外部表格的行列含义。

## 验证

- 主窗口顶部显示“打开文件”，不再显示“打开历史”。
- 历史数据页内部仍显示“打开 CSV / Excel”。
- 顶部按钮仍连接到原有 `history_viewer_open` 流程。
- 现有自动测试和源码编译通过。

# CSV/Excel 中文化与绘图交互限制设计

## 1. 目标

本次只做两项小范围优化：

1. 新生成的 CSV/Excel 中，全部已知用户可见标签和值使用中文。
2. 所有光谱绘图区禁用鼠标滚轮和右键缩放，只保留左键框选放大与
   左键双击复位。

文件命名、单/多设备导出决策、处理算法、采集接收、全量原始帧缓存及恢复
格式均保持不变。

## 2. 导出中文化

采用“内部字段稳定、导出时集中翻译”的实现：

- 存储协调器、处理快照和 `.part/.zgs` 内部字段继续使用现有键，避免破坏
  恢复兼容性。
- 最终 CSV/Excel 导出器通过同一个本地化模块转换标签和值。
- 已知英文标签全部转换，包括设备、帧数、时间、串口、生产序列号、积分
  时间、触发模式、同步方式、处理模式、背景/参考、强度校准、airPLS、
  处理管线版本和拒绝帧统计。
- `True/False` 输出为“是/否”。
- 处理模式输出为“原始强度/扣背景/吸光度/自定义公式”。
- 触发和同步模式输出中文名称。
- 未知扩展字段保留原标签和值，防止第三方元数据丢失。

CSV 固定表头调整为：

- `# ZGCAI 批量光谱数据`
- `# 设备编号`
- `# 帧数`
- `# 导出时间`
- 数据列为“像素序号”“波长 (nm)”以及
  “第 0001 帧_序号_XXXXXX_时间戳_...”。

Excel 保留“采集概要 + 每设备一个工作表”的结构：

- 概要标签和值中文化。
- 每设备工作表的 `Pixel/Wavelength/Frame/Seq` 改为对应中文。
- 工作表名称、数据排列和每帧一列、每像素一行的结构不变。

已有导出文件不回写、不重命名。

## 3. 绘图交互

限制同时应用于实时光谱和历史数据，并覆盖 legacy 与 PyQtGraph 后端。

### 3.1 保留

- 左键拖动框选 X/Y 区域放大。
- 左键双击恢复完整视图。
- 光标十字线。
- 固定 Y 轴和自动缩放开关。

### 3.2 禁用

- 鼠标滚轮缩放。
- 右键点击、右键拖动、右键缩放和右键菜单。

legacy 后端在控件事件入口接受并忽略滚轮与非左键操作；PyQtGraph 后端在
自定义 ViewBox 中接受并忽略滚轮与非左键拖动，同时继续关闭菜单。工具提示
只说明“左键框选放大、左键双击复位”。

## 4. 测试与交付

测试覆盖：

- CSV 固定标签、元数据标签、枚举值和布尔值中文化。
- Excel 概要和设备页列头中文化。
- 未知元数据原样保留。
- legacy 后端滚轮和右键操作不改变坐标范围。
- PyQtGraph 后端在依赖可用时验证相同交互。
- 左键框选与双击复位继续有效。
- 存储端到端文件数量、数据内容和文件命名不变。

完成后运行完整测试、编译检查、部署副本一致性检查，并同步
`deploy/rock4bplus/app`。用户现有 Excel、Word、PDF、诊断包和已生成数据
文件不纳入提交。

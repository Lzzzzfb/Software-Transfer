# ZGCAI 光谱仪工作站用户指南

## 1. 界面

界面保留原软件布局关系：顶部主工具带负责采集、背景、参考、同步、设备发现和选项；第二层工具带负责处理模式、公式、X 轴、图片和对比曲线；左侧显示设备卡片与批量存储设置；中央包含实时光谱、历史数据和诊断；底部显示设备数、显示帧率、缺帧、存储队列和磁盘余量。

## 2. 连接设备

1. 启动软件后会自动扫描常见 USB 串口光谱仪。
2. 也可点击“查找设备”立即扫描；非标准 USB 标识的设备可在左侧选择串口和波特率后手动连接。
3. 连接成功后设备卡片显示端口、生产序列号、像素数、起始波长和参数。
4. 断线后软件保留端口信息并按 1、2、4、8、16、30 秒退避重连。

## 3. 采集和同步

左侧选择“连续采集”或“单次采集”，顶部选择同步模式：

- 独立采集：所有启用设备独立启动。
- 软件同步：上位机依次向所有启用设备发送启动命令。
- 内部硬同步：先布防从机，最后启动所选主机。
- 外部硬同步：所有设备只布防并等待外部信号。

硬同步脉冲由下位机自动输出，上位机不会为每帧发送 `0x54`。
选择内部硬同步时必须先在左侧选中物理主机。程序会自动将从机设为外部触发、主机设为软件主机，收到全部 ACK 后才启动；外部硬同步会将所有设备设为外部触发。

设备连接后会用约 1.65 秒分步读取版本、校准和参数。在状态显示初始化完成前不会启动采集；采集中修改参数会被拒绝，需先停止。

## 4. 背景、参考和处理

选择左侧设备后，点击顶部“背景”或“参考”记录当前光谱。记录按生产序列号和像素配置保存，其他设备不会自动套用。

处理模式：

- 原始强度：显示强度校准后的当前数据。
- 扣背景：`I - Idark`。
- 吸光度：`-log10((I-Idark)/(I0-Idark))`。
- 自定义公式：支持 `I`、`Idark`/`Ib`、`I0`、`x`，以及 `+ - * / **`、`log10`、`log`、`loge`、`abs`、`sqrt`。

自定义公式不执行 Python 代码；属性访问、下标、导入、未知函数、异常幂指数、除零和非有限结果都会被拒绝并写入诊断日志。

## 5. 批量存储

左侧可设置：

- 每批帧数：1–1000，默认 500。
- 格式：CSV + Excel、仅 CSV、仅 Excel。
- 是否随采集自动启动批量存储。

布局：

- CSV：每台设备每批一个文件。
- Excel：每批一个工作簿，含“采集概要”和每台设备独立工作表。
- 每一帧占一列，每一个像素占一行。
- 每台设备使用自己的像素和波长列，因此不同设备、波段和像素数能够明确区分。

采集期间每帧先写入 `.part` 恢复缓存。存储队列达到 50% 时告警，达到 90% 时请求受控停止；不会因绘图刷新降帧而静默丢失存储帧。

## 6. 历史和诊断

历史页最多 12 个标签，每个标签最多 64 条曲线，支持打开本软件输出的 CSV 和 Excel。诊断页显示每台设备的接收帧、缺帧、重复、乱序、回绕，以及带时间戳的连接、处理和存储日志。

## 7. 恢复

异常退出后，数据目录中可能保留 `.part` 文件。缓存读取器会验证文件头和逐帧 CRC32，只恢复完整记录并报告被截断或损坏的尾部。正常停止且批量文件全部导出成功后，临时缓存自动删除；导出失败时保留缓存供恢复。

## 8. 无硬件演示

```powershell
python main.py --simulate
```

模拟模式创建 4 台设备，每台 4096 像素，并生成动态峰形光谱，可验证界面、处理、诊断和批量存储流程。

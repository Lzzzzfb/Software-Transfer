# ZGCAI 光谱仪工作站用户指南

## 1. 启动与连接

在项目目录打开 PowerShell：

```powershell
.\.venv\Scripts\python.exe main.py
```

软件启动后自动枚举串口并发送版本查询。只有返回合法光谱仪设备信息的端口才会显示，普通串口即使 VID/PID 相同也不会误连接。点击顶部“查找设备”可立即重新扫描；界面不再提供手动指定串口、波特率或手动连接控件。

## LK-MD2202 电机与扫描

实时光谱页下方的电机区域只显示 X/M1、Y/M2 的常用操作。点击“自动识别并连接”
后，软件会排除已被光谱仪占用的串口，并通过只读 Modbus 身份寄存器确认
LK-MD2202。需要手动串口、地址、波特率、方向反转或驱动参数时，点击“电机设置”。

建议驱动参数为 1.8°、8 细分、50% 运行电流、零点限位、4800 pulse 终点、
停止电流无锁定、加减速 10000、位置速度 10000 pps。X/Y 行程均为 15 mm，
换算固定为 320 pulse/mm。“恢复建议默认值”只修改表单；点击“应用”并确认差异
后才写驱动板，且必须回读一致才成功。

“清零”只改变本次运行的软件坐标，不运动；软件坐标可以小于 0。“回零”按当前
软件坐标移动到 0；“机械回零”调用驱动板零点限位重新建立可信坐标。软件零点和
校准状态不会掉电保存。扫描不强制机械回零，但未校准时会要求确认越程风险。

如果机械回零后电机被卡在零点，可在对应轴速度框中输入带符号速度并点击“脱离卡死”。
软件最迟会在 1 秒或 4800 pulse 理论运行时间内写入速度 0；如果驱动板第一次仍上报
运行中，会补发位置急停并继续有限次数确认。确认停止后不要求重新连接，但该轴仍为
未校准，必须由操作员重新执行机械回零。只有持续无法确认停止时才会进入安全锁。

扫描参数 `x、y、n、m` 表示宽为 `x`、高为 `y*n` 的蛇形矩阵执行 `m` 轮。
每轮 X 走 `n+1` 个交替方向行程，Y 正向走 `n` 个行程；X/Y 步数把完整行程细分，
步时是相邻动作之间的等待时间。存在已连接光谱仪时，每轮先连续采集，扫描完成后
停止并保存，再在不采集状态下返回本轮起点。未连接光谱仪时，“开始扫描”会自动
执行同一条纯电机扫描和返回路径，不启动采集，也不生成独立扫描清单。扫描参数、
轮次和结果进入“诊断”日志，需要时通过“导出诊断包”导出。停止或故障后不会盲目
自动复位。

连接成功后，设备卡显示 COM 口、生产序列号、有效像素、起始波长和增益。断线后软件按退避策略自动重连。自动存储在每次启动时都保持未勾选。

## 2. 总控与单机采集

在“保存图片”右侧选择连续或单次采集，顶部选择同步模式。

- 顶部“开始/停止”是总控按钮，一次控制所有勾选“参与总控”的设备。
- 设备卡内“开始/停止”只控制该设备，并且总是先把该设备配置为软件触发；多张卡可以同时独立运行。
- 单机任务正在运行、停止或保存时，顶部总控不会接管设备。
- 总控任务活动期间，设备卡按钮仍可点击，但请求会被安全拒绝并写入诊断记录。
- 顶部总控启动前会检查全部已连接设备，而不只是“参与总控”的设备；只要任何设备仍未完全空闲就拒绝启动。

同步方式：

- 独立采集：总控设备均使用软件触发并开始采集。
- 软件同步：上位机在同一任务中配置并启动全部总控设备。
- 内部硬同步：从机设为外部触发，所选主机设为软件主机；全部配置 ACK 成功后从机先启动、主机最后启动。
- 外部硬同步：全部设备设为外部触发并等待外部信号。

硬同步脉冲由下位机自动输出，上位机不会在逐帧路径发送 `0x54`。选择内部硬同步时，应先用设备卡左侧的单选圆点选定参与总控的主机。

## 3. 背景、参考和参数保护

- 顶部“背景”和“参考”作用于全部“参与总控”的设备，并沿用当前同步方式。
- 设备卡内“背景”和“参考”只作用于该设备。
- 每次操作都会真正执行一次新的单次采集，不会复用屏幕上缓存的旧帧。
- 顶部批量操作只有在全部设备都收到新帧后才整批提交，任一设备失败都不会替换已有背景/参考。
- 任何采集、停止或保存任务存在时，所有背景/参考请求都会被拒绝。

积分时间和“设备参数与校准”仅在目标设备完全空闲时可应用。现有波长校准系数顺序保持不变：上位机为 `C1,C2,C3,C4`，下位机传输为 `C4,C3,C2,C1`。

处理模式：

- 原始强度：显示逐像素强度校准后的当前数据。
- 扣背景：`I - Idark`。
- 吸光度：`-log10((I-Idark)/(I0-Idark))`。
- 自定义公式：支持 `I`、`Idark`/`Ib`、`I0`、`x`，以及 `+ - * / **`、`log10`、`log`、`loge`、`abs`、`sqrt`。

自定义公式使用受限表达式解析，不执行 Python 代码；属性访问、下标、导入、未知函数、异常幂指数、除零和非有限结果都会被拒绝。

### 3.1 强度校准

打开设备卡的“设备参数与校准”，在“强度校准”区导入 CSV 或 TXT。
文件可以是单列系数，也可以是 `Pixel,Coefficient` 两列；两列格式中的
Pixel 必须从 0 连续递增。系数数量必须与该设备有效像素数完全相同，且
每个系数都必须是有限正数。

软件按“生产序列号 + 有效像素数”保存校准记录，设备下次握手成功后自动
加载。没有可靠生产序列号的设备只在当前运行期间使用校准。导入失败不会
替换已生效的旧记录；“清除”会同时清除当前内存和该设备的持久化记录。

处理顺序固定为：当前帧、背景和参考分别乘同一组逐像素系数，再执行原始、
扣背景、吸光度或自定义公式。这样绘图区和 CSV/Excel 中保存的是同一份最终
处理结果。

### 3.2 airPLS 基线校正

顶部处理栏的“airPLS”开关控制全局默认状态，“airPLS 参数”设置 λ、差分
阶数和最大迭代次数。设备参数页可选择“跟随全局设置”，也可保存该设备的
独立覆盖。设备覆盖同样按生产序列号自动恢复。

airPLS 始终在所选处理模式之后执行，包括吸光度和自定义公式。参数和开关
在采集开始时冻结，因此采集中修改只影响下一次任务。airPLS 显示处理在有界
后台线程中执行：每台设备最多保留一个正在处理的帧和一个最新待处理帧，
不会拖慢串口接收或全量存储；校正后的显示 FPS 可能低于未校正显示。

## 4. 光谱图操作

- 左键按住并拖动：显示半透明矩形，松开后同时放大 X、Y。
- 左键双击：恢复初始视图。
- 鼠标滚轮和右键：不执行缩放，避免误操作。
- “Y 轴设置…”：在弹窗中启用固定 Y 轴并输入最小值、最大值。

固定 Y 后，新采集帧不会改变当前 Y 范围，因此曲线不会随强度跳动；左键框选仍可继续缩放 Y，人工缩放后的范围也会保持。双击恢复完整 X 和用户设置的初始 Y。取消固定后恢复实时自动 Y 范围。

像素序号和原始强度使用完整十进制整数；波长、吸光度和处理结果使用定点小数，不显示科学计数法。标签过宽时软件会减少刻度数量并动态扩大边距。

## 5. 参数输入防误触

所有数值框隐藏上下加减箭头，并屏蔽鼠标滚轮、上/下方向键、PageUp 和 PageDown；只能点击后直接输入、粘贴或删除数值。所有下拉框也屏蔽滚轮，但仍可点击展开或使用键盘选择。绘图区同样屏蔽滚轮和右键缩放。

## 6. 批量存储

点击顶部“选项”，可设置每批帧数（1–1000）、CSV + Excel、仅 CSV或仅 Excel，并主动勾选“采集时自动批量存储”。每批默认 500 帧，默认格式为 CSV + Excel；自动批量存储每次启动均恢复为未勾选。

- CSV + Excel：单设备任务每批只生成该设备的 CSV；多设备任务每批只生成
  一个 Excel 工作簿。
- 仅 CSV：无论单设备还是多设备，每台设备每批分别生成一个 CSV。
- 仅 Excel：无论单设备还是多设备，每批生成一个工作簿。
- Excel 工作簿包含“采集概要”和每台设备的独立工作表；概要中记录处理模式、
  强度校准 ID 和 airPLS 参数。
- 每帧一列、每像素一行；每台设备使用自己的像素数和波长列。
- 已知的表头、元数据标签及处理/触发/同步方式使用中文；未知扩展字段原样保留。
- 历史页可直接打开新版中文 CSV/Excel，也继续兼容旧版英文 `Pixel/Wavelength` 表头。

文件名示例：

```text
20260723_多设备_B0001.xlsx
20260723_SN003_B0001.csv
20260723_SN003_B0001.xlsx
```

以上第三个文件只会在单设备选择“仅 Excel”时生成；单设备选择
“CSV + Excel”时只生成第二个 CSV。

文件名只记录日期、设备生产序列号和批次号，不记录时分秒、采集模式或串口号。序列号不可用时使用内部设备编号。同名文件不会覆盖，自动追加 `_01`、`_02`。停止后，按钮依次显示“停止中”和“保存中”；停止 ACK、尾帧静默等待和 CSV/Excel 导出在后台完成，界面仍可响应。

真实设备采集期间，每个完整帧都先写入 `.part` 临时安全缓存，正常停止时
封存并核对完整帧数与持久化帧数。未勾选自动批量存储时，最近一次正常结束
的普通采集会保留为待保存缓存，此时工具栏“保存光谱”可用。点击后直接使用
采集开始时冻结的处理、批次、格式和数据目录，在后台生成与自动存储相同的
CSV/Excel；不弹出文件选择窗口。

“保存光谱”保存的是最近一次从开始到停止的完整普通采集任务，而不是最后
500 帧。多设备任务保存该任务包含的全部设备。若尚未保存便开始下一次普通
采集，旧缓存会无提示清除，并在诊断页记录覆盖事件。正常退出程序也会清除
尚未保存的正常缓存。背景和参考采集不会覆盖它。

勾选自动批量存储后继续在所选 CSV/Excel 全部导出并核对成功后删除缓存，
不会再生成手动保存候选。任务异常、帧数不一致、导出失败或缓存删除失败时保留
`.part/.zgs` 供恢复，并在诊断页显示完整路径。`.part/.zgs` 不属于正常
生成的 CSV/Excel 文件。

## 7. 历史、诊断与恢复

顶部不再提供“新建页面”；历史数据页内部仍保留“新建页面”，每页最多 64 条曲线。诊断页显示接收帧、缺帧、重复、乱序、回绕及连接、处理、控制和存储日志。

点击“恢复缓存”可读取 `.part`。恢复程序校验文件头和逐帧 CRC32，只恢复完整记录，并报告截断或损坏的尾部。

## 8. 无硬件演示与验证

```powershell
.\.venv\Scripts\python.exe main.py --simulate
.\.venv\Scripts\python.exe tools\run_ui_control_validation.py
```

模拟模式创建 4 台 4096 像素设备。验证工具自动运行总控 10 轮、并行单机、冲突拒绝、单次采集、背景/参考和批量存储，并在 `data/validation/` 生成未纳入 Git 的报告。
